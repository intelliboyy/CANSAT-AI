# CanSat AI

Machine learning pipeline for **weather condition classification** and **air temperature prediction**, built from hourly meteorological observations. The layout is ready for GitHub: source package, datasets, docs, tests, and CI.

## Features

- Preprocess timestamps into hour / day / month / weekday features
- Standard-scale sensor readings for classification
- Random Forest weather-label classifier
- Linear regression model for `Temp_C`
- One-command training script and GitHub Actions tests

## Setup

Python 3.10+ is recommended.

```bash
git clone https://github.com/<your-username>/CANSAT_AI.git
cd CANSAT_AI
python -m venv .venv
```

Windows (PowerShell):

```powershell
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
```

macOS / Linux:

```bash
source .venv/bin/activate
pip install -e ".[dev]"
```

You can also install with `pip install -r requirements.txt` if you do not want an editable package.

## Usage

From the repository root:

```bash
# Rebuild processed features, then train both models
python scripts/train.py
```

After `pip install -e .`, individual stages:

```bash
python -m cansat_ai.preprocess
python -m cansat_ai.classify_weather
python -m cansat_ai.predict_temperature
```

Without installing the package, add `src` to `PYTHONPATH`:

```bash
# Windows PowerShell
$env:PYTHONPATH = "src"
python -m cansat_ai.preprocess
python -m cansat_ai.classify_weather
python -m cansat_ai.predict_temperature
```

```bash
# macOS / Linux
PYTHONPATH=src python -m cansat_ai.preprocess
PYTHONPATH=src python -m cansat_ai.classify_weather
PYTHONPATH=src python -m cansat_ai.predict_temperature
```

Skip preprocessing if `data/processed/preprocessed_weather_data.csv` is already current:

```bash
python scripts/train.py --skip-preprocess
```

## Tests

```bash
pytest -q
```

## Dataset

Hourly weather records with temperature, dew point, relative humidity, wind speed, visibility, pressure, and a categorical weather label. Raw data lives in `data/raw/`; the processed table is regenerated by `preprocess.py`.
